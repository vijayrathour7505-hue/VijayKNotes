🐍 Python Conditional Statements

BCA (AI) — Python Programming — Chapter 4

1. What are Conditional Statements?

Conditional statements are used to make decisions in a Python program. They allow a program to execute different blocks of code depending on whether a particular condition is True or False.

In simple words, a conditional statement tells the computer what action should be performed when a specific condition is satisfied.

Conditional statements are very important in programming because real-world applications need to make decisions based on different situations.

Example: If a student's marks are greater than or equal to 40, the program can display "Pass". Otherwise, it can display "Fail".

2. Why are Conditional Statements Used?

Conditional statements help a program make logical decisions. Without conditions, a program would execute instructions in the same sequence every time.

They are commonly used for checking age, marks, passwords, login status, numbers, user choices, eligibility and many other situations.

Common Uses

  • Checking whether a student has passed or failed.
  • Checking whether a number is positive or negative.
  • Checking voting eligibility.
  • Checking username and password.
  • Calculating grades.
  • Making decisions in AI and machine learning programs.

3. Types of Conditional Statements in Python

Python mainly provides the following conditional statements:

Statement Purpose
if Executes code when a condition is True.
if-else Chooses between two alternatives.
if-elif-else Checks multiple conditions.
Nested if Places one if statement inside another.

4. if Statement

The if statement is the simplest conditional statement in Python. It executes a block of code only when the given condition is True.

Syntax

if condition:
    statement

Notice the colon (:) after the condition. Python uses indentation to identify the block of code that belongs to the if statement.

Example 1: Checking Age

age = 20

if age >= 18:
    print("You are an adult")
Output:
You are an adult

Example 2: Checking Positive Number

number = 10

if number > 0:
    print("Positive number")
Output:
Positive number

5. if-else Statement

The if-else statement is used when there are two possible outcomes. If the condition is True, the if block is executed. If the condition is False, the else block is executed.

Syntax

if condition:
    statement1
else:
    statement2

Example 1: Pass or Fail

marks = 65

if marks >= 40:
    print("Pass")
else:
    print("Fail")
Output:
Pass

Example 2: Even or Odd

number = 8

if number % 2 == 0:
    print("Even")
else:
    print("Odd")
Output:
Even

6. if-elif-else Statement

The if-elif-else statement is used when a program needs to check more than two conditions.

Python checks the conditions from top to bottom. When it finds the first True condition, its block is executed and the remaining conditions are skipped.

Syntax

if condition1:
    statement
elif condition2:
    statement
else:
    statement

Example: Grade Calculation

marks = 85

if marks >= 90:
    print("Grade A+")
elif marks >= 80:
    print("Grade A")
elif marks >= 70:
    print("Grade B")
elif marks >= 60:
    print("Grade C")
else:
    print("Grade D")
Output:
Grade A

7. Nested if Statement

A nested if statement means an if statement inside another if statement.

Nested conditions are useful when the second condition should be checked only after the first condition becomes True.

Example

age = 20
has_id = True

if age >= 18:

    if has_id:
        print("Entry allowed")
    else:
        print("ID is required")

else:
    print("Entry not allowed")
Output:
Entry allowed

8. Comparison Operators with Conditions

Comparison operators are frequently used with conditional statements. They compare two values and return either True or False.

Operator Meaning
== Equal to
!= Not equal to
> Greater than
< Less than
>= Greater than or equal to
<= Less than or equal to

Example

a = 10
b = 20

if a < b:
    print("a is smaller than b")
Output:
a is smaller than b

9. Logical Operators with Conditions

Logical operators are used to combine two or more conditions.

Operator Meaning
and True when all conditions are True.
or True when at least one condition is True.
not Reverses the result of a condition.

Example using and

age = 20
marks = 75

if age >= 18 and marks >= 40:
    print("Eligible")
Output:
Eligible

Example using or

day = "Sunday"

if day == "Sunday" or day == "Saturday":
    print("Weekend")
Output:
Weekend

10. Real-Life Example — Voting Eligibility

Conditional statements can be used to check whether a person is eligible to vote based on their age. 

age = 21

if age >= 18:
    print("You are eligible to vote")
else:
    print("You are not eligible to vote")
Output:
You are eligible to vote

11. Finding the Largest of Two Numbers

Conditional statements can compare two numbers and determine which number is larger. 

a = 50
b = 30

if a > b:
    print("a is greater")
else:
    print("b is greater")
Output:
a is greater

12. Conditional Statements in AI

Conditional statements are also useful in Artificial Intelligence programs. An AI system often needs to make decisions based on input data or conditions.

For example, a simple AI-based system may classify a value into different categories depending on certain conditions.

Simple Example

score = 85

if score >= 80:
    print("High score")
elif score >= 50:
    print("Medium score")
    else:
    print("Low score")
Output:
High score
