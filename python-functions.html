🐍 Python Functions

BCA (AI) — Python Programming — Chapter 6

1. What is a Function?

A function is a reusable block of code that performs a specific task. Instead of writing the same code repeatedly, we can define it once inside a function and call it whenever required.

Functions make programs easier to understand, organize, test and maintain. They are an important concept in structured and modular programming.

Simple Definition: A function is a block of reusable code designed to perform a particular task.

2. Why are Functions Used?

Functions help programmers divide a large program into smaller and manageable parts. Each function can perform a particular operation.

Advantages of Functions

  • Code reusability.
  • Reduces code repetition.
  • Makes programs easier to understand.
  • Makes debugging easier.
  • Improves program organization.
  • Makes testing easier.
  • Useful for large software projects.

3. Types of Functions in Python

Python functions can be broadly divided into two categories.

Type Description
Built-in Functions Functions already provided by Python.
User-defined Functions Functions created by the programmer.

Examples of Built-in Functions

print("Hello")
len("Python")
max(10, 20, 30)
min(10, 20, 30)
sum([10, 20, 30])

4. Creating a Function

In Python, a function is created using the def keyword.

Syntax

def function_name():
    statement

The function name should describe what the function does. The statements inside the function must be properly indented.

Example

def greet():
    print("Hello, Vijay!")

greet()
Output:
Hello, Vijay!

5. Function with Parameters

A parameter is a variable specified inside the parentheses of a function definition. Parameters allow us to pass data to a function.

Example

def greet(name):
    print("Hello", name)

greet("Vijay")
Output:
Hello Vijay

Here, name is a parameter and "Vijay" is the value passed to the function.

6. Function with Multiple Parameters

A function can accept more than one parameter. Multiple parameters are separated by commas.

Example

def add(a, b):
    print(a + b)

add(10, 20)
Output:
30

Another Example

def student(name, age):
    print("Name:", name)
    print("Age:", age)

student("Vijay", 20)
Output:
Name: Vijay
Age: 20

7. return Statement

The return statement is used to send a value back from a function to the place where the function was called.

A function can calculate a result and return it instead of directly printing the result.

Example

def add(a, b):
    return a + b

result = add(10, 20)

print(result)
Output:
30
Important: print() displays a value, while return sends a value back from the function.

8. Function with Default Arguments

A default argument is a parameter that already has a default value. If the user does not provide a value, Python uses the default value.

Example

def greet(name="Student"):
    print("Hello", name)

greet()
greet("Vijay")
Output:
Hello Student
Hello Vijay

9. Keyword Arguments

Keyword arguments allow us to pass values to a function by explicitly specifying the parameter name.

Example

def student(name, age):
    print("Name:", name)
    print("Age:", age)

student(age=20, name="Vijay")
Output:
Name: Vijay
Age: 20

10. Positional Arguments

In positional arguments, values are assigned to parameters according to their position. 

def student(name, age):
    print(name)
    print(age)

student("Vijay", 20)
Output:
Vijay
20

11. Function Returning Multiple Values

Python allows a function to return multiple values. These values are commonly returned together as a tuple. 

def calculate(a, b):

    addition = a + b
    multiplication = a * b

    return addition, multiplication


x, y = calculate(10, 5)

print("Addition:", x)
print("Multiplication:", y)
Output:
Addition: 15
Multiplication: 50

12. Local and Global Variables

A variable created inside a function is generally called a local variable. It can normally be accessed only inside that function.

A variable created outside functions is called a global variable and can be accessed from different parts of the program.

Example

name = "Vijay"

def show():
    age = 20

    print(name)
    print(age)

show()
Output:
Vijay
20

13. Recursive Function

A recursive function is a function that calls itself. Recursion is useful for solving problems that can be divided into smaller similar problems.

Example: Factorial

def factorial(n):

    if n == 0:
        return 1

    return n * factorial(n - 1)


print(factorial(5))
Output:
120
Important: A recursive function should have a proper base condition to stop recursion.

14. Lambda Function

A lambda function is a small anonymous function. It can have any number of arguments but generally contains a single expression.

Syntax

lambda arguments: expression

Example

square = lambda x: x * x

print(square(5))
Output:
25

15. Function Calling Another Function

One function can call another function. This helps divide a large task into smaller logical operations. 

def message():
    print("Welcome to VijayKNotes")


def start():
    message()
    print("Python Functions")


start()
Output:
Welcome to VijayKNotes
Python Functions

16. Functions in AI and Data Processing

Functions are extremely important in Artificial Intelligence and Machine Learning programs. Large AI programs are divided into smaller functions so that each function can perform a specific task.

For example, separate functions can be created for data cleaning, calculations, prediction and result processing.

Simple Example

def calculate_average(numbers):

    total = sum(numbers)

    return total / len(numbers)


marks = [80, 75, 90, 85]

average = calculate_average(marks)

print("Average:", average)
Output:
Average: 82.5
BCA (AI) Point: Functions are used extensively when building data-processing pipelines and machine-learning programs.

17. Common Mistakes in Functions

  • Forgetting the def keyword.
  • Forgetting parentheses.
  • Forgetting the colon after the function definition.
  • Incorrect indentation.
  • Calling a function with the wrong number of arguments.
  • Confusing print() with return.
  • Forgetting to call the function after defining it.
Remember: Defining a function does not execute it. The function must be called to execute its code.
