Chapter 8: Python Lists

Complete BCA(AI) Notes – Theory, Examples, Outputs & Practice

1. What is a List?

A list is an ordered collection of elements. Lists are one of the most commonly used data structures in Python.

A list can store multiple values in a single variable. It can contain numbers, strings, Boolean values and even other lists. 

numbers = [10, 20, 30, 40]

print(numbers)
Output:
[10, 20, 30, 40]
Important: Lists are ordered, mutable and allow duplicate values.

2. Creating a List

names = ["Vijay", "Aman", "Rahul"]

marks = [80, 75, 90]

mixed = ["Python", 100, True, 25.5]

print(names)
print(marks)
print(mixed)
Output:
['Vijay', 'Aman', 'Rahul']
[80, 75, 90]
['Python', 100, True, 25.5]

3. List Indexing

List indexing starts from 0. 

fruits = ["Apple", "Banana", "Mango"]

print(fruits[0])
print(fruits[1])
print(fruits[2])
Output:
Apple
Banana
Mango

Negative Indexing

fruits = ["Apple", "Banana", "Mango"]

print(fruits[-1])
print(fruits[-2])
Output:
Mango
Banana

4. List Slicing

Slicing is used to extract a portion of a list. 

numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])
print(numbers[:3])
print(numbers[2:])
Output:
[20, 30, 40]
[10, 20, 30]
[30, 40, 50]

5. Changing List Elements

Lists are mutable, which means their elements can be changed. 

marks = [70, 80, 90]

marks[1] = 95

print(marks)
Output:
[70, 95, 90]

6. Adding Elements

append()

append() adds an element at the end of the list. 

numbers = [10, 20, 30]

numbers.append(40)

print(numbers)
Output:
[10, 20, 30, 40]

insert()

insert() adds an element at a specified position. 

numbers = [10, 20, 30]

numbers.insert(1, 15)

print(numbers)
Output:
[10, 15, 20, 30]

extend()

extend() adds multiple elements to a list. 

a = [1, 2, 3]
b = [4, 5, 6]

a.extend(b)

print(a)
Output:
[1, 2, 3, 4, 5, 6]

7. Removing Elements

remove()

numbers = [10, 20, 30, 40]

numbers.remove(30)

print(numbers)
Output:
[10, 20, 40]

pop()

pop() removes an element using its index. 

numbers = [10, 20, 30]

numbers.pop(1)

print(numbers)
Output:
[10, 30]

clear()

numbers = [10, 20, 30]

numbers.clear()

print(numbers)
Output:
[]

8. List Length

len() returns the number of elements in a list. 

names = ["Vijay", "Aman", "Rahul"]

print(len(names))
Output:
3

9. Checking an Element

The in operator checks whether an element exists in a list. 

fruits = ["Apple", "Mango", "Banana"]

print("Mango" in fruits)
print("Orange" in fruits)
Output:
True
False

10. Sorting a List

sort()

numbers = [50, 10, 40, 20, 30]

numbers.sort()

print(numbers)
Output:
[10, 20, 30, 40, 50]

Descending Order

numbers = [50, 10, 40, 20, 30]

numbers.sort(reverse=True)

print(numbers)
Output:
[50, 40, 30, 20, 10]

11. reverse() Method

numbers = [10, 20, 30, 40]

numbers.reverse()

print(numbers)
Output:
[40, 30, 20, 10]

12. count() Method

count() tells how many times an element occurs in a list. 

numbers = [10, 20, 10, 30, 10]

print(numbers.count(10))
Output:
3

13. index() Method

index() returns the position of the first occurrence of an element. 

names = ["Vijay", "Aman", "Rahul"]

print(names.index("Rahul"))
Output:
2

14. Copying a List

The copy() method creates a copy of a list. 

numbers = [10, 20, 30]

new_numbers = numbers.copy()

print(new_numbers)
Output:
[10, 20, 30]

15. Looping Through a List

A for loop can be used to access every element of a list. 

fruits = ["Apple", "Banana", "Mango"]

for fruit in fruits:
    print(fruit)
Output:
Apple
Banana
Mango

16. List of Numbers and Calculations

marks = [80, 70, 90, 85, 75]

print("Maximum =", max(marks))
print("Minimum =", min(marks))
print("Total =", sum(marks))
print("Number of Marks =", len(marks))
Output:
Maximum = 90
Minimum = 70
Total = 400
Number of Marks = 5

17. Nested Lists

A list can contain another list. Such a structure is called a nested list. 

students = [
    ["Vijay", 85],
    ["Aman", 90],
    ["Rahul", 78]
]

print(students[0])
print(students[0][0])
print(students[0][1])
Output:
['Vijay', 85]
Vijay
85

18. List Comprehension

List comprehension provides a short and readable way to create a new list. 

squares = [x * x for x in range(1, 6)]

print(squares)
Output:
[1, 4, 9, 16, 25]

With Condition

even = [x for x in range(1, 11) if x % 2 == 0]

print(even)
Output:
[2, 4, 6, 8, 10]

19. Lists in AI and Data Processing

Lists are very useful in Artificial Intelligence and Data Science. They can store collections of data such as values, features, labels and text records.

  • Student marks
  • Training data
  • Feature values
  • Class labels
  • Text tokens
  • Sensor readings
  • Prediction results

Example

temperatures = [30, 32, 31, 35, 33]

average = sum(temperatures) / len(temperatures)

print("Average =", average)
Output:
Average = 32.2

In real AI applications, large datasets are usually handled using specialized libraries such as NumPy and Pandas, but understanding Python lists is an important foundation.

20. Common List Mistakes

  • Using an index that does not exist.
  • Forgetting that indexing starts from 0.
  • Confusing append() and extend().
  • Using remove() with an index instead of a value.
  • Forgetting brackets [ ].
  • Changing a list while incorrectly iterating through it.
Example:
numbers.remove(20) removes the value 20, while numbers.pop(2) removes the element at index 2.

21. Practice Programs

Program 1: Find Sum of List

numbers = [10, 20, 30, 40, 50]

print("Sum =", sum(numbers))

Program 2: Find Largest Number

numbers = [25, 80, 45, 90, 60]

print("Largest =", max(numbers))

Program 3: Find Smallest Number

numbers = [25, 80, 45, 90, 60]

print("Smallest =", min(numbers))

Program 4: Count Even Numbers

numbers = [10, 15, 20, 25, 30, 35]

count = 0

for number in numbers:
    if number % 2 == 0:
        count += 1

print("Even numbers =", count)

Program 5: Take List Input

numbers = []

for i in range(5):
    number = int(input("Enter number: "))
    numbers.append(number)

print("List =", numbers)
