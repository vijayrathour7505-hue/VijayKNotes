🐍 Python Loops

BCA (AI) — Python Programming — Chapter 5

1. What are Loops?

A loop is a programming structure used to execute the same block of code repeatedly. Instead of writing the same statement many times, we can use a loop to repeat the statement automatically.

Loops are one of the most important concepts in programming because they reduce code repetition and make programs shorter, easier to understand and easier to maintain.

Example: If we want to print numbers from 1 to 100, writing 100 print statements would be inefficient. A loop can do this with only a few lines.

2. Why are Loops Used?

Loops are used whenever a task needs to be repeated. They are especially useful when the number of repetitions is large or depends on some condition.

Common Uses of Loops

  • Printing numbers repeatedly.
  • Processing elements of a list.
  • Reading multiple values.
  • Searching data.
  • Calculating totals and averages.
  • Processing strings.
  • Repeating tasks until a condition changes.
  • Processing data in AI and Machine Learning.

3. Types of Loops in Python

Python mainly provides two types of loops:

Loop Purpose
for loop Used to iterate over a sequence or a known range of values.
while loop Repeats a block of code while a condition remains True.

Python also provides control statements such as break, continue and pass to control the execution of loops.

4. for Loop

The for loop is used to iterate over the elements of a sequence such as a list, tuple, string or range.

The loop takes one item at a time from the sequence and executes the block of code for that item.

Syntax

for variable in sequence:
    statement

Example 1: Print Numbers

for i in range(1, 6):
    print(i)
Output:
1
2
3
4
5

Example 2: Print Names

names = ["Vijay", "Rahul", "Aman"]

for name in names:
    print(name)
Output:
Vijay
Rahul
Aman

5. range() Function

The range() function is commonly used with the for loop. It generates a sequence of numbers.

Basic Syntax

range(start, stop, step)

The start value specifies where the sequence begins. The stop value specifies where it ends, but the stop value is not included. The step specifies the difference between consecutive values.

Example

for i in range(1, 10, 2):
    print(i)
Output:
1
3
5
7
9
Important: The stop value in range() is excluded.

6. while Loop

The while loop repeatedly executes a block of code as long as a specified condition remains True.

It is useful when we do not know exactly how many times the loop should execute beforehand.

Syntax

while condition:
    statement

Example

i = 1

while i <= 5:
    print(i)
    i += 1
Output:
1
2
3
4
5
Important: Make sure the condition eventually becomes False. Otherwise, the program may enter an infinite loop.

7. break Statement

The break statement is used to immediately terminate a loop. When Python encounters break, it exits the loop and continues with the statement after the loop.

Example

for i in range(1, 10):

    if i == 5:
        break

    print(i)
Output:
1
2
3
4

8. continue Statement

The continue statement skips the remaining code of the current iteration and moves to the next iteration of the loop.

Example

for i in range(1, 6):

    if i == 3:
        continue

    print(i)
Output:
1
2
4
5

9. pass Statement

The pass statement is a null statement. It does nothing when executed.

It is useful when we want to create a block of code that will be implemented later.

Example

for i in range(5):

    if i == 3:
        pass

    print(i)
Output:
0
1
2
3
4

10. Nested Loops

A nested loop is a loop inside another loop. The inner loop executes completely for every iteration of the outer loop.

Nested loops are commonly used for tables, patterns, matrices and multidimensional data.

Example

for i in range(1, 4):

    for j in range(1, 4):

        print(i, j)
Output:
1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
3 3

11. for Loop with String

A string is a sequence of characters, so a for loop can be used to access each character one by one. 

name = "Vijay"

for letter in name:
    print(letter)
Output:
V
i
j
a
y

12. for Loop with List

A for loop can process every element of a list. This is very useful when working with collections of data. 

marks = [75, 82, 91, 68]

for mark in marks:
    print(mark)
Output:
75
82
91
68

13. Sum of Numbers Using Loop

Loops can be used to calculate the sum of multiple numbers. 

total = 0

for i in range(1, 6):
    total = total + i

print("Total =", total)
Output:
Total = 15

14. Multiplication Table

A loop can be used to generate a multiplication table automatically. 

number = 5

for i in range(1, 11):
    print(number, "x", i, "=", number * i)
Output:
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50

15. Loops in AI and Data Processing

Loops are very important in Artificial Intelligence and Machine Learning because AI programs often need to process large amounts of data.

For example, a program may need to process thousands of records, calculate values, check conditions or prepare data before it is given to a machine learning algorithm. 

data = [10, 20, 30, 40, 50]

for value in data:

    if value >= 30:
        print(value)
Output:
30
40
50
BCA (AI) Point: Understanding loops is important before learning data processing, NumPy, Pandas and Machine Learning.

16. Common Mistakes in Loops

  • Forgetting indentation.
  • Using the wrong range() values.
  • Forgetting to update the variable in a while loop.
  • Creating an infinite while loop.
  • Using break or continue incorrectly.
  • Confusing for loop and while loop.
Remember: In Python, indentation is very important. Statements inside a loop must be properly indented.

18. Chapter Summary

Loops allow a Python program to repeat instructions efficiently. Python provides two main loops: for and while.

  • for — Used to iterate over sequences.
  • while — Repeats while a condition is True.
  • break — Stops the loop.
  • continue — Skips the current iteration.
  • pass — Does nothing and acts as a placeholder.
  • Nested loop — A loop inside another loop.

Loops are fundamental for programming and are also heavily used in data processing and Artificial Intelligence applications.
