🐍 Python Operators

Python Programming — Chapter 3

1. What are Operators?

Operators are special symbols or keywords used to perform operations on values and variables.

For example, the + operator is used for addition and the > operator is used for comparison. 

a = 10
b = 5

print(a + b)
Output: 
15

2. Types of Python Operators

Python provides several types of operators:

  • Arithmetic Operators
  • Assignment Operators
  • Comparison Operators
  • Logical Operators
  • Identity Operators
  • Membership Operators
  • Bitwise Operators

3. Arithmetic Operators

Arithmetic operators are used to perform mathematical operations.

Operator Name Example
+ Addition a + b
- Subtraction a - b
* Multiplication a * b
/ Division a / b
% Modulus a % b
** Exponentiation a ** b
// Floor Division a // b

Example

a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)
print(a ** b)
print(a // b)
Output: 
13
7
30
3.3333333333333335
1
1000
3

4. Assignment Operators

Assignment operators are used to assign values to variables.

Operator Example Meaning
= x = 5 Assign
+= x += 5 x = x + 5
-= x -= 5 x = x - 5
*= x *= 5 x = x * 5
/= x /= 5 x = x / 5
%= x %= 5 x = x % 5

Example

x = 10

x += 5

print(x)

x -= 3

print(x)
Output: 
15
12

5. Comparison Operators

Comparison operators compare two values. The result is either True or False.

Operator Meaning
== Equal to
!= Not equal to
> Greater than
< Less than
>= Greater than or equal to
<= Less than or equal to

Example

a = 10
b = 5

print(a == b)
print(a != b)
print(a > b)
print(a < b)
print(a >= b)
print(a <= b)
Output: 
False
True
True
False
True
False

6. Logical Operators

Logical operators are used to combine conditional statements.

Operator Meaning
and Returns True if both conditions are True
or Returns True if at least one condition is True
not Reverses the result

Example

age = 20

print(age > 18 and age < 30)

print(age > 25 or age == 20)

print(not(age > 18))
Output: 
True
True
False

7. Identity Operators

Identity operators are used to check whether two variables refer to the same object.

Operator Meaning
is Returns True if objects are the same
is not Returns True if objects are different

Example

a = [1, 2, 3]
b = a

print(a is b)
Output: 
True

8. Membership Operators

Membership operators are used to check whether a value exists in a sequence.

Operator Meaning
in Returns True if value exists
not in Returns True if value does not exist

Example

numbers = [10, 20, 30, 40]

print(20 in numbers)

print(50 not in numbers)
Output: 
True
True

9. Bitwise Operators

Bitwise operators work on the binary representation of numbers.

Operator Name
& AND
| OR
^ XOR
~ NOT
<< Left Shift
>> Right Shift

Example

a = 5
b = 3

print(a & b)
print(a | b)
print(a ^ b)
Output: 
1
7
6

10. Operator Precedence

Operator precedence determines the order in which operations are performed.

Multiplication and division are performed before addition and subtraction.

Example

result = 10 + 5 * 2

print(result)
Output: 
20

11. Practice Program

Write a Python program to perform basic arithmetic operations on two numbers. 

a = 20
b = 10

print("Addition =", a + b)
print("Subtraction =", a - b)
print("Multiplication =", a * b)
print("Division =", a / b)
print("Modulus =", a % b)

12. Summary

  • Arithmetic operators perform mathematical operations.
  • Assignment operators assign values to variables.
  • Comparison operators compare values.
  • Logical operators combine conditions.
  • Identity operators compare object identity.
  • Membership operators check whether a value exists.
  • Bitwise operators work with binary values.
