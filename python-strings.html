Chapter 7: Python Strings

Complete BCA(AI) Notes – Theory, Examples, Outputs & Practice

1. What is a String?

A string is a sequence of characters. In Python, strings are used to store text such as names, sentences, addresses, messages and other textual data.

Strings can be written inside single quotes, double quotes or triple quotes. 

name = "Vijay"
city = 'Meerut'
message = """Welcome to Python"""
Example Values:
Vijay
Meerut
Welcome to Python
Important: Python strings are immutable. This means that once a string is created, its individual characters cannot be changed directly.

2. Creating Strings

Single Quotes

name = 'Vijay'
print(name)
Output:
Vijay

Double Quotes

course = "BCA AI"
print(course)
Output:
BCA AI

Triple Quotes

text = """Python
is
easy"""

print(text)
Output:
Python
is
easy

3. String Indexing

Indexing is used to access individual characters of a string. Python indexing starts from 0. 

name = "Python"

print(name[0])
print(name[1])
print(name[5])
Output:
P
y
n

Negative Indexing

Negative indexing starts from the end of the string. 

name = "Python"

print(name[-1])
print(name[-2])
Output:
n
o

4. String Slicing

Slicing is used to extract a part of a string.

Syntax

string[start:end]

The starting index is included but the ending index is excluded. 

name = "Python"

print(name[0:3])
print(name[2:6])
Output:
Pyt
thon

Using Step

name = "Python"

print(name[::2])
Output:
Pto

5. String Length – len()

The len() function returns the number of characters present in a string. 

name = "Vijay"

print(len(name))
Output:
5

6. String Concatenation

Concatenation means joining two or more strings. The + operator is used for concatenation. 

first = "Vijay"
last = "Rathour"

full_name = first + " " + last

print(full_name)
Output:
Vijay Rathour

7. String Repetition

The * operator can repeat a string multiple times. 

word = "Python "

print(word * 3)
Output:
Python Python Python

8. Common String Methods

Python provides many built-in methods for processing strings.

upper()

text = "python"

print(text.upper())
Output:
PYTHON

lower()

text = "PYTHON"

print(text.lower())
Output:
python

capitalize()

text = "python programming"

print(text.capitalize())
Output:
Python programming

title()

text = "python programming"

print(text.title())
Output:
Python Programming

strip()

Removes extra spaces from the beginning and end. 

text = "   Python   "

print(text.strip())
Output:
Python

9. replace() Method

The replace() method replaces one part of a string with another. 

text = "I like Java"

new_text = text.replace("Java", "Python")

print(new_text)
Output:
I like Python

10. split() Method

The split() method divides a string into a list. 

text = "Python is easy"

words = text.split()

print(words)
Output:
['Python', 'is', 'easy']

11. join() Method

The join() method joins elements of a list into a string. 

words = ["Python", "is", "easy"]

sentence = " ".join(words)

print(sentence)
Output:
Python is easy

12. find() Method

The find() method returns the index of the first occurrence of a specified value. 

text = "Python Programming"

print(text.find("Programming"))
Output:
7

13. count() Method

The count() method counts how many times a value occurs. 

text = "banana"

print(text.count("a"))
Output:
3

14. Checking Strings

startswith()

text = "Python Programming"

print(text.startswith("Python"))
Output:
True

endswith()

text = "Python.py"

print(text.endswith(".py"))
Output:
True

isdigit()

text = "12345"

print(text.isdigit())
Output:
True

isalpha()

text = "Python"

print(text.isalpha())
Output:
True

15. String Formatting

String formatting is used to insert variables into a string.

Using f-string

name = "Vijay"
course = "BCA(AI)"

print(f"My name is {name}")
print(f"My course is {course}")
Output:
My name is Vijay
My course is BCA(AI)
Note: f-strings are commonly used because they make string formatting simple and readable.

16. Escape Characters

Escape characters are used to represent special characters inside strings.

New Line – \n

print("Python\nProgramming")
Output:
Python
Programming

Tab – \t

print("Python\tProgramming")
Output:
Python Programming

Double Quote – \"

print("He said \"Hello\"")
Output:
He said "Hello"

17. Strings are Immutable

Python strings cannot be changed character by character after they are created. 

text = "Python"

# text[0] = "J"   # This will cause an error

Instead, create a new string. 

text = "Python"

text = "J" + text[1:]

print(text)
Output:
Jython

18. String Membership Operators

The in and not in operators check whether a value exists inside a string. 

text = "Python Programming"

print("Python" in text)
print("Java" in text)
print("Java" not in text)
Output:
True
False
True

19. Strings in AI and Data Processing

Strings are very important in Artificial Intelligence and Data Science because a large amount of data is available in textual form.

Examples include:

  • Chatbot messages
  • User reviews
  • Social media text
  • Customer feedback
  • Search queries
  • Natural Language Processing (NLP)
  • Text classification
  • Sentiment analysis

Example: Cleaning Text Data

text = "   Python is Amazing   "

clean_text = text.strip().lower()

print(clean_text)
Output:
python is amazing

Such operations are often used as a basic step before processing text in AI and machine learning applications.

20. Common Mistakes

  • Forgetting quotation marks around text.
  • Using an invalid string index.
  • Confusing string concatenation with numeric addition.
  • Forgetting that string indexing starts from 0.
  • Trying to modify a string character directly.
  • Using the wrong spelling of string methods.
Example: 
age = 20

# print("Age: " + age)  # Error

print("Age: " + str(age))
Output:
Age: 20

21. Practice Programs

Program 1: Count Characters

text = input("Enter a string: ")

print("Length =", len(text))

Program 2: Convert to Uppercase

text = input("Enter a string: ")

print(text.upper())

Program 3: Reverse a String

text = input("Enter a string: ")

print(text[::-1])

Program 4: Check Palindrome

text = input("Enter a string: ")

if text == text[::-1]:
    print("Palindrome")
else:
    print("Not Palindrome")

Program 5: Count Vowels

text = input("Enter a string: ")

count = 0

for ch in text:
    if ch.lower() in "aeiou":
        count += 1

print("Vowels =", count)

  • Slicing extracts a portion of a string.
  • Strings are immutable.
  • len() returns the length of a string.
  • + joins strings.
  • * repeats strings.
  • Python provides many useful string methods.
