🐍 Python Variables & Data Types

Python Programming — Chapter 2

1. What is a Variable?

A variable is a name used to store data in a Python program. 

  
name = "Vijay"  
age = 20

2. Variable Example

Variables can store different types of values such as text and numbers. 

  
name = "Vijay"  
age = 20  
  
print(name)  
print(age)

3. Python Data Types

Python has different data types for storing different kinds of values.

  • int — Whole numbers
  • float — Decimal numbers
  • str — Text or string
  • bool — True or False
  • list — Collection of items
  • tuple — Ordered collection
  • set — Collection of unique values
  • dict — Key-value collection

4. Integer (int)

Integer is used to store whole numbers without decimal points. 

  
age = 20  
  
print(age)

5. Float (float)

Float is used to store decimal numbers. 

  
price = 99.50  
  
print(price)

6. String (str)

String is used to store text. 

  
name = "Vijay"  
  
print(name)

7. Boolean (bool)

Boolean has two values: True and False. 

  
is_student = True  
  
print(is_student)

8. List

A list is used to store multiple values in a single variable. 

  
students = ["Vijay", "Rahul", "Aman"]  
  
print(students)

9. Tuple

A tuple is an ordered collection of values. 

  
numbers = (10, 20, 30)  
  
print(numbers)

10. Set

A set is a collection of unique values. 

  
numbers = {10, 20, 30}  
  
print(numbers)

11. Dictionary

A dictionary stores data in key-value pairs. 

  
student = {  
    "name": "Vijay",  
    "age": 20  
}  
  
print(student)

12. type() Function

The type() function is used to check the data type of a value. 

  
age = 20  
  
print(type(age))
